# Agent instructions

AI newsletter pipeline demo (WAT framework: Workflows, Agents, Tools) that researches a topic, generates infographics, drafts an HTML newsletter, and sends it via Gmail.
Stack: Python, Groq/LLaMA-3.3-70b, Claude, Kie.ai, Google Sheets/Gmail APIs.
Run locally: see README.md Setup and Usage sections, pip install -r requirements.txt plus the per-tool commands under tools/.
Status: reference repo only, not a live product or service, dormant since 2026-05-02.
A CLAUDE.md already exists here with fuller framework detail, read that first for anything beyond this stub.
